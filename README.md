# MC 팩 편집기 (프로토타입)

마인크래프트 Java 리소스팩 폴더를 VS Code처럼 열어서 바로 고치는 맥 네이티브 앱 (SwiftUI).

## 빌드 / 실행
```
./build_app.sh
open MC팩편집기.app
open MC팩편집기.app --args <팩폴더> [처음 열 파일 상대경로]   # 검증용
```

## 지금 되는 것 (v0.1)
- 시작 화면: 새 팩 만들기(이름·설명 미리보기·지원 버전 범위·아이콘·빈 ko_kr) + resourcepacks의 내 팩 목록(zip은 폴더로 풀어서 열기)
- 사이드바 "텍스처": 블록·아이템·엔티티·GUI·파티클 등 15종 + 팩 전용 네임스페이스, 모든 텍스처를 아이콘 격자로(크기 조절, 검색, 하위 폴더, 팩에 있는 것/바닐라만)
- 사이드바 "크리에이티브 탭": 건축·색깔·자연·기능·레드스톤·도구·전투·음식·재료·생성 알·관리자 11개 탭을 게임 순서 그대로
  - 탭 목록은 설치된 마크 jar의 CreativeModeTabs 코드를 마크에 딸린 javap로 풀어서 읽음(색 묶음은 코드의 색 순서로 펼침), 버전별 캐시
  - 아이콘은 items/<id>.json → 모델을 따라가서 찾고, 블록처럼 모델이 있는 건 게임 인벤토리 각도(gui)로 3D 렌더
  - 누르면 아이콘 텍스처 편집, 오른쪽 클릭으로 모델·상황별 정의
- 한국어: 텍스처·아이템·크리에이티브 탭에 게임 ko_kr 이름 표시, 한국어·영어 둘 다 검색
- 뒤로가기(툴바·Cmd+[)는 진짜 이전 페이지로, 목록의 스크롤 위치·검색어·필터 유지
- 그림판 도구·색·불투명도·붓 크기·섞기·투명 잠금·격자·배경은 파일을 바꾸거나 앱을 다시 켜도 그대로 (3D 칠하기 붓도 공유)
- "바꾼 것 미리보기": 팩이 바꾼 파일만 전/후 비교, 새 파일·바뀐 파일 집계, 복사만 하고 안 고친 파일 정리
- 안 건드린 파일은 팩에 안 들어감: 바닐라를 열면 복사하지 않고 그대로 보여주다가, 고쳐서 저장할 때만 팩에 씀(애니메이션 등 짝 .mcmeta도 그때 같이). 고쳤다가 되돌려 저장해 바닐라와 같아지면 팩에서 빼고 빈 폴더도 정리. zip 내보내기 때 바닐라와 똑같은 파일은 자동으로 뺌
- 화면 모드: 밝게(기본)/어둡게/시스템 따라 (보기 메뉴)
- 폴더 열기 (Cmd+O, 기본 위치 resourcepacks), 파일 트리, 파일명 검색, 앱으로 돌아오면 자동 새로고침
- PNG 그림판: 연필/지우개/채우기/스포이드, 붓 크기, 불투명도, 블렌드/그대로 찍기, 투명 잠금, 실행취소, 확대, 격자, 배경 바꾸기
  - 비-premultiplied RGBA 버퍼로 편집해서 반투명 픽셀 색이 저장 후에도 그대로 유지됨
- 이미지 적용: 캔버스에 드롭 / 가져오기. 기본은 이미지 크기 그대로(텍스처가 그 크기로 바뀜), 비율 유지·자르기·늘리기도 가능
- 선택: 사각 선택·마술봉(허용 오차, 이어진 곳만), Shift 더하기·Option 빼기, 전체·해제·반전
  - 선택이 있으면 연필·지우개·채우기(3D 스킨 칠하기 포함)가 그 안에서만 칠해짐
  - 복사·잘라내기·붙여넣기(다른 앱 그림도), 지우기, 지금 색으로 채우기, 선택한 곳만 뒤집기
  - 이동 도구·방향키로 떼어서 옮기기, Return 확정·Esc 취소
- JSON·mcmeta·텍스트·셰이더 편집, JSON 문법 검사, 정렬
- 새 PNG, Finder에서 보기, 휴지통으로 이동
- 모두 저장 (Cmd+S), 종료 시 저장 안 한 파일 경고
- zip 내보내기 (Shift+Cmd+E, pack.mcmeta 없으면 만들어 줌), resourcepacks에 설치
- 언어 표 편집기 (assets/*/lang/*.json을 열면 자동, 툴바 "언어")
  - 키 | 기준(바닐라 en_us·같은 언어·팩의 다른 언어) | 이 팩의 값, 팩에 없는 키는 바닐라 값이 흐리게 보이고 쓰면 추가

  - 찾아 바꾸기 (팩에 없는 바닐라 문장에도 적용 가능), 키 추가(자동완성), 빈 값으로, 바닐라로 되돌림, 일괄 되돌리기
  - § 서식 코드 게임 글씨 미리보기, 원시 JSON 보기 전환
  - 새 언어: 바닐라 언어 덮어쓰기 또는 나만의 언어(pack.mcmeta language에 등록)
  - 바닐라 문장은 설치된 마크에서 읽음: en_us는 versions/<v>/<v>.jar, 나머지는 assets/indexes + objects
